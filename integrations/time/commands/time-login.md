# Time Login — команда удалена

Отдельный логин в Time больше не нужен. Старая схема (токен из браузерной cookie
`MMAUTHTOKEN` в `.env`) снята с поддержки вместе с коннектором `time@ai-hub`.

## Что сделать вместо этого

Плагин `dodo-time` авторизуется сам по OAuth: при первом вызове любого его инструмента
открывается браузер — вход через корпоративный Google, затем экран согласия Тайма.
Копировать токены никуда не нужно, в `.env` ничего не пишется.

Если плагина ещё нет — с согласия пользователя:

```bash
claude plugin uninstall time@ai-hub
claude plugin install dodo-time@dodo-ai-marketplace
```

Проверка после рестарта сессии — вызов `time_whoami`.

Если пользователь отказал Тайму в доступе или отозвал его в профиле, первый же вызов
инструмента вернёт ссылку для повторной привязки.

## Заодно предложи убрать

`TIME_TOKEN`, `TIME_BOT_TOKEN`, `TIME_BASE_URL` из `.env` — новый коннектор их не читает.
