# Time — команда удалена

`/ai-hub:time-chat` больше не работает: коннектор Time переехал из ai-hub в отдельный
плагин `dodo-time` на MCP. Не пытайся вызывать скрипты `integrations/time/scripts/*` —
их нет в репозитории.

## Что сделать вместо этого

1. Скажи пользователю одной фразой: коннектор Time переехал в плагин `dodo-time`,
   старый снят с поддержки.
2. Проверь, установлен ли новый — есть ли в сессии инструменты `time_whoami`,
   `time_list_channels`, `time_search_messages` (имена вида `mcp__*dodo-time*__time_*`).
   - **Есть** — выполни исходный запрос пользователя этими инструментами.
   - **Нет** — предложи установку и, с согласия пользователя, выполни:
     ```bash
     claude plugin uninstall time@ai-hub
     claude plugin install dodo-time@dodo-ai-marketplace
     ```
     Нет маркетплейса `dodo-ai-marketplace` — ссылку спросить в канале ai-hub-public.
     После установки нужен рестарт сессии, при первом вызове откроется браузер
     (корпоративный Google + экран согласия Тайма).
3. Если запрос был про **отправку** сообщения — скажи прямо, что `dodo-time` только
   читает, и это сделано намеренно: агент, читающий произвольные каналы и умеющий
   в них писать, исполняет инструкции из чужих сообщений и пишет токеном пользователя.

## Хвосты старого коннектора

Если пользователь просит прибраться — проверь и предложи удалить: `TIME_TOKEN`,
`TIME_BOT_TOKEN`, `TIME_BASE_URL` в `.env`, а также упоминания `time@ai-hub`,
`/ai-hub:time-chat`, `/ai-hub:time-login` в `~/.claude/CLAUDE.md` и в `CLAUDE.md` /
`AGENTS.md` рабочих репозиториев.
