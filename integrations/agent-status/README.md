# agent-status

Мод Claude Code для десктопного приложения Claude (вкладка Code): показывает статус каждой сессии прямо в сайдбаре, чтобы при десятке параллельных агентов было видно, где нужны вы.

## Что делает

**Иконка в начале названия сессии**

| Иконка | Значит | Как ставится |
|---|---|---|
| 🔄 | агент работает | вы отправили сообщение |
| ⏳ | ход закончен, идёт фоновая задача | в сессии есть незавершённый фоновый `Bash`, `Monitor` или `Agent` |
| ⚠️ | агент ждёт вашего ответа | вопрос с вариантами или план на одобрение — сразу; иначе по последнему ответу |
| ❌ | работа упёрлась, сама не продолжится | по последнему ответу |
| ✅ | задача готова | по последнему ответу |

Решение ⚠️ / ❌ / ✅ по тексту ответа принимает Haiku через `$.model.complete`: около 500–700 токенов на ход. Остальное — без модели. Токены основной модели мод не тратит.

**Над полем ввода**
- список фоновых задач сессии с тем, сколько каждая идёт (3 строки, кнопка «Показать все»). Если команда ожидания называет прогон, рядом ссылка на него: `databricks jobs get-run <run_id> --profile <profile>` → страница прогона в Databricks (хост из `~/.databrickscfg`), `gh run watch <run_id> --repo <owner>/<repo>` → GitHub Actions;
- при ✅ — строка «Задача готова» с кнопкой «Принято», которая снимает галочку.

**Сайдбар (по желанию)** — когда вы пишете в сессию, она переезжает в указанную секцию. Секции с заданным префиксом (по умолчанию 📌) мод не трогает.

**`/agent-status-usage`** — сколько токенов Haiku мод потратил сегодня.

При открытии сессии без иконки мод ставит её по последнему ответу агента.

## Установка

В терминале:

```bash
claude plugin install agent-status@ai-hub --scope user
```

В приложении: «+» у поля ввода → Plugins → Add plugin → `agent-status` из `ai-hub`.

Затем добавьте разрешения в `~/.claude/settings.json`, чтобы вызовы мода не проходили через классификатор auto mode и не спрашивали подтверждения:

```json
"permissions": {
  "allow": [
    "mcp__ccd_session_mgmt__get_session",
    "mcp__ccd_session_mgmt__set_session_title",
    "mcp__ccd_sidebar__list_sections",
    "mcp__ccd_sidebar__move_sessions"
  ]
}
```

Мод подхватится в новых сессиях; в открытых — после `/reload-plugins` или перезапуска приложения.

## Настройки

В терминале — `/config`, строки плагина `agent-status`. Или вручную в `~/.claude/settings.json`:

```json
"pluginConfigs": {
  "agent-status@ai-hub": {
    "options": {
      "openSection": "Открытые задачи",
      "keepPrefix": "📌"
    }
  }
}
```

- `openSection` — название секции сайдбара, куда переезжает сессия, когда вы в неё пишете. Пусто (по умолчанию) — сессии не переносятся.
- `keepPrefix` — сессии из секций, чьё название начинается с этого префикса, не переносятся. По умолчанию `📌`.

## Ограничения

- Работает в десктопном приложении: иконки и перенос опираются на его инструменты сайдбара. В терминале остаются только список задач и кнопка.
- Запросы разрешений на инструменты мод не видит — такую сессию подсвечивает встроенная точка статуса.
- Фоновые задачи, запущенные до загрузки мода, в список и в ⏳ не попадают.
- Название, заданное вручную, приложение меняет только с вашего подтверждения; если вы отказали, мод больше не трогает название этой сессии.
- Где Claude Code управляется организацией, события `classic.*` (в т. ч. `Stop` со списком фоновых задач) до установленного пользователем плагина не доходят, поэтому мод ведёт фоновые задачи сам по вызовам инструментов и уведомлениям о завершении.
