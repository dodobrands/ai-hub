# hub-bugfix: от жалобы до PR за один заход

Цель скорости: не чинить симптом в одном месте, чтобы через неделю тот же класс
всплыл в соседней интеграции. Один баг здесь обычно это класс (резолвер, контракт
вывода, bash 3.2), и все его копии чинятся одним PR.

## 1. Зафиксируй симптом

Что звали (команда, скрипт, аргументы), где (standalone, overlay, marketplace; bash или
zsh; macOS или Linux), что ждали, что получили (stdout, stderr, rc). Если входа мало,
выясни недостающее у пользователя одним вопросом, но сначала посмотри сам.

Типовые корни по симптому:

| Симптом | Где искать |
| --- | --- |
| `/<script>.sh: No such file or directory`, путь начинается со слэша | резолвер в `commands/*.md` или `SKILL.md`: glob в zsh, нет сценария установки |
| «ничего не найдено», а данные есть | тихий отказ: `curl -s`, `2>/dev/null`, неверный ID из URL, ошибка в теле при 200 |
| 401 при валидном токене | склейка URL (лишний или недостающий слэш), токен не из того `.env` (`HUB_ENV_FILE`, overlay) |
| работает у одного, падает у другого | bash 3.2 против 5, zsh против bash, `LC_ALL`, версия python |
| трейсбек питона в ответе | необработанный `HTTPError` или кодировка stdout |

## 2. Воспроизведи без сети

Сначала тест, потом фикс. Bats-тест в `integrations/<name>/tests/` со стабом `curl`,
который отдаёт ответ из жалобы (см. `hub-script-dev`, раздел 6). Для резолверов:
сценарий в `tests/path-resolution.sh`. Убедись, что тест **красный** на текущем коде.

Если воспроизвести без сети нельзя, запиши в PR точные шаги ручного воспроизведения.

## 3. Почини корень

Минимальный фикс, который делает тест зелёным и соблюдает контракт `hub-script-dev`.
Не расширяй PR попутными улучшениями: их в «Вне PR».

## 4. Найди копии

```bash
grep -rn '<характерный фрагмент дефекта>' integrations/ tests/
```

Тот же резолвер, тот же паттерн `curl`, та же функция разбора URL в других интеграциях
чинятся в этом же PR, каждая со своим тестом. Если копий много и они в чужой зоне,
перечисли их в «Вне PR».

Проверь открытые PR, не чинит ли кто-то то же самое:

```bash
gh pr list --state open --search '<ключевое слово>'
```

Есть такой: дополни его или договорись, а не открывай дубль.

## 5. Закрой

1. Bump patch-версии затронутых плагинов (обе стороны манифеста) и корневой.
2. `bash .claude/skills/hub-preflight/scripts/preflight.sh`: FAIL 0.
3. `hub-self-review`, линзы 1, 3, 4 и 9 обязательно.
4. PR: в «Проблема» исходный симптом и воспроизведение, в «Доказательства» тест,
   который был красным до фикса.
5. Если баг пришёл из ретро или чужой жалобы, ответь там ссылкой на PR.
