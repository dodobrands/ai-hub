# hub-script-dev: как писать скрипты интеграций, чтобы ревью было не о чем

Скрипты зовёт агент, а не человек. Агент верит коду возврата и stdout. Поэтому главный
грех здесь **тихий отказ**: команда упала, а наружу ушли rc=0 и «ничего не найдено».
Это самый частый класс находок на ревью, за ним идут контракт вывода и пустые тесты.

## 1. Контракт вывода

- **stdout** только полезный результат: JSON для машинных команд (парсится `jq` в
  **каждой** ветке, включая ошибку) или явно оговорённый текст. Никаких прогресс-строк.
- **stderr** диагностика и ошибки, одной понятной строкой: что не так и что делать.
  Без питоновского трейсбека поверх сообщения.
- **Код возврата**: 0 только при реальном успехе. HTTP 4xx/5xx, сетевая ошибка, пустой
  токен, `{"code": <не 0>}` в теле при HTTP 200: всё это rc != 0 и текст в stderr.
- Идентификатор созданного объекта (id комментария, треда, файла) печатается в stdout,
  чтобы агент мог на него сослаться.

## 2. HTTP

```bash
resp=$(curl -sS -w '\n%{http_code}' --max-time 30 -H "Authorization: Bearer $TOKEN" "$url") || {
  echo "ошибка сети при запросе $endpoint" >&2; exit 1; }
code=${resp##*$'\n'}; body=${resp%$'\n'*}
case "$code" in 2??) ;; *) echo "API $code на $endpoint: $(printf '%s' "$body" | head -c 300)" >&2; exit 1 ;; esac
```

- `-sS`, а не `-s`: иначе ошибка curl пропадает. Никаких `2>/dev/null` и `|| true` на пути API.
- Таймаут обязателен (`--max-time`); для загрузки файлов больше, но тоже явный.
- Тело может сообщить об ошибке при HTTP 200: проверь поле статуса, если у API оно есть.
- Перед опасной операцией (публичный файл, удаление, массовая запись) отказывай **до**
  запроса, если входные данные не прошли проверку.

## 3. Ловушки bash

- Ориентир bash 3.2 (`/bin/bash` на маке). Нельзя: `mapfile`/`readarray`, `declare -A`,
  `${x,,}`/`${x^^}`, `&>>`, `|&`, `${arr[-1]}`, `declare -n`.
- `local x=$(cmd)` теряет код возврата `cmd` (SC2155): пиши `local x; x=$(cmd)`.
- Функция, вызванная в `if`, `||`, `&&` или внутри `$(...)` аргумента, исполняется без
  `set -e`: проверяй код явно. Подстановку выноси отдельной строкой перед вызовом.
- Разбор аргументов: неизвестный `--флаг` это ошибка (`--*) echo "unknown flag $1" >&2; exit 2`),
  а не позиционный аргумент. Опечатка `--dryrun` не должна делать боевую запись.
- `--dry-run` не ходит в сеть на запись и не пишет файлы. Если пишет, так и задокументируй.
- Временные файлы только `mktemp`, секреты и откаты с `chmod 600`, удаление в `trap ... EXIT`.
- Python из bash: `python3 -I`, вывод проверяй под `LC_ALL=C` (`ensure_ascii=False` там падает).

## 4. Резолвер путей в commands/*.md и SKILL.md

Сниппет исполняется в шелле пользователя (на маке zsh) из произвольного cwd. Сценарии:
standalone-клон, subtree внутри overlay-репозитория, marketplace-кеш плагина, skill,
симлинкнутый в `~/.claude/skills`. Правила:

- Никаких glob в подстановке: в zsh несовпавший `*` обрывает всю подстановку целиком.
- Кандидаты: сначала `$CLAUDE_PLUGIN_ROOT/scripts` с проверкой маркер-файла, потом поиск
  по форме пути от корня git (`find ... -path '*/integrations/<name>/scripts'`).
- Блок оборачивай маркерами `# resolve-<name>-dir:start` / `:end`, тогда его видит
  гейт `tests/path-resolution.sh`. Новую интеграцию добавь в его таблицу маркеров.

## 5. Секреты и .env

```bash
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
source "$SCRIPT_DIR/../../hub-meta/scripts/load-env.sh"
hub_load_env "$SCRIPT_DIR"
```

Новый токен добавь в список секретов в `load-env.sh` и в `.env.example` (с плейсхолдером).
Токен не печатается ни в stdout, ни в stderr, ни в отладочный дамп запроса.

## 6. Тесты (bats, без сети)

Образец: `integrations/kaiten/tests/endpoint-normalization.bats`. Песочница с копией
скрипта и `load-env.sh`, `.env` с фейковым токеном, `curl`-стаб первым в `PATH`.

Тест ловит регрессию, только если:

- **Стаб умеет отказывать**: режимы 200, 200 с ошибкой в теле, 401, 500, обрыв сети
  (выход curl != 0). На каждую ветку отказа ассерт `[ "$status" -ne 0 ]` и непустой stderr.
- **Проверяет контракт**: `echo "$output" | jq -e .` в ветках, где обещан JSON.
- **Проверяет, что ушло в сеть**: стаб пишет аргументы в файл, тест сверяет метод, URL,
  тело, экранирование `"` и `\`, таймаут.
- **Изолирован от окружения**: не зависит от переменных разработчика (`env -i` или явный
  `unset`), от `team-config.json`, от наличия `python3` там, где проверяется его отсутствие.
- **Под bash 3.2**: после `[[ ... ]]` в середине теста ставь `|| false`, иначе упавшее
  условие тест не роняет.
- **Прошёл мутацию**: сломай руками проверяемую строку скрипта и убедись, что тест
  покраснел. Тест, который зелёный на сломанном коде, хуже отсутствия теста.

Запуск: `bats integrations/<name>/tests/` (CI подхватывает новые `.bats` сам).

## 7. Агент должен узнать о фиче

Новый флаг или подкоманда идут не только в README, а в `commands/*.md` или `SKILL.md`,
которые агент реально читает: когда звать, пример вызова, что вернётся, как выглядит отказ.
